# Data Dictionary

| Variable | Description |
| --- | --- |
| `period` | Monthly period. |
| `region` | Province/city/region name or anonymized label. |
| `issuer_group` | Anonymized issuer group. |
| `fiscal_revenue` | Local fiscal revenue indicator. |
| `fiscal_expenditure` | Local fiscal expenditure indicator. |
| `fiscal_self_sufficiency` | Fiscal revenue divided by fiscal expenditure. |
| `land_transfer_revenue` | Land-transfer revenue indicator. |
| `land_revenue_share` | Land-transfer revenue divided by fiscal revenue. |
| `gdp_growth` | Regional GDP growth control. |
| `debt_pressure_proxy` | Proxy for regional refinancing/debt pressure. |
| `bond_issuance` | Bond issuance amount. |
| `repayment` | Bond repayment amount. |
| `net_financing` | Bond issuance minus repayment. |
| `weighted_yield` | Weighted observed yield. |
| `benchmark_yield` | Benchmark yield used for spread calculation. |
| `credit_spread` | Weighted yield minus benchmark yield. |
| `remaining_maturity` | Remaining maturity in years. |
| `turnover` | Turnover or liquidity proxy. |
| `implied_rating` | Implied rating segment. |
